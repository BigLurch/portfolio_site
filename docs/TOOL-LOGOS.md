# Tool logo sources

The Python, Pandas, NumPy, scikit-learn, MLflow, FastAPI, Docker, GitHub Actions, Streamlit, AWS and Linux marks are from Simple Icons 13.21.0:
https://github.com/simple-icons/simple-icons/tree/13.21.0

Simple Icons is distributed under CC0-1.0. Logo colors are presentation choices; names remain visible beside all marks.

The Azure mark is from Devicon 2.16.0:
https://github.com/devicons/devicon/tree/v2.16.0

Evidently uses a generic eye symbol in this version, as in the approved preview. It is not the official Evidently logo.
